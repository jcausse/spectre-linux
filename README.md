# Linux on HP Spectre

This is a set of fixes and customizations I applied to my **Ubuntu 26.04** installation on my `HP Spectre x360 2-in-1 Laptop 16-aa0097nr`. Note that some of this fixes are GNOME-specific and/or bash-specific.

I actually tested most of these fixes on Fedora Workstation before moving to Ubuntu, so they should also work on Fedora Workstation (GNOME Wayland), but might require you to change `apt` invocations to `dnf`.

* [WiFi D3Cold disable](https://github.com/jcausse/spectre-fedora/blob/main/guides/wifi-d3cold-disable.md)
* [Touchpad Palm Rejection](https://github.com/jcausse/spectre-fedora/blob/main/guides/touchpad-palm-rejection.md)
* [Audio Mute LEDs](https://github.com/jcausse/spectre-fedora/blob/main/guides/audio-mute-leds.md)
* [Disable Touchpad When Mouse Connected](https://github.com/jcausse/spectre-fedora/blob/main/guides/disable-touchpad-when-external-mouse-connected.md)
* [Disable Touchpad Acceleration](https://github.com/jcausse/spectre-fedora/blob/main/guides/disable-touchpad-acceleration.md)
